# Navigation and Interface Overview

At the top of the screen, the system features a top bar that includes Qonnec branding to indicate the system or **company name**, **a search icon** for quick access to records, and a **user profile section** which contains user settings, logout options, or profile management features. The system also includes a **collapsible side navigation panel** on the left side of the screen that acts as the main navigation menu. This panel can be opened or closed to help you quickly find and access the tools and information you need. Below is a simple explanation of each section in the navigation panel:

  - **Dashboard:** This is the main page you see when you log in. It gives you a quick overview of important business details, such as profits, sales, and summaries of your work, all in one place.

  - **Vehicles:** This section lets you manage information about the vehicles in your shop. You can view and update details about the cars you’re working on.

  - **Customers:** Use this section to keep track of your customers’ information. It helps you manage their details and add new customers as needed.

  - **Product Inquiry:** This area is likely for looking up details about products, such as checking if an item is available or learning more about the parts you sell.

  - **Operations:** This section helps you handle tasks like creating job orders or setting up estimates and repairs for your work. Under this are operations such as:

| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Inspection         | This link is where you can manage vehicle inspections. You might use it to check a vehicle’s condition and record any issues that need to be fixed.                        |
| Estimate           | This section allows you to create estimates for repair or service jobs. You can use it to calculate and share the expected costs with your customers before starting work. |
