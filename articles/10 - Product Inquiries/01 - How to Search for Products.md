# How to Search for Products

Use the following procedure to **search for products.**

1.  **Access Product Inquiry**: Navigate to the "PRODUCT INQUIRY" section from the left sidebar menu.

2.  **Enter Product Details**: In the search fields, input relevant information such as:

<!-- end list -->

  - **Product Name**: Type the name of the product.

  - **Part No**.: Enter the part number if known.

  - **Manufacturer**: Select or type the manufacturer name.

  - **Category**: Choose the category if applicable.

  - **Supplier**: Select the supplier from the dropdown.

  - **Storage** **Location**: Specify Rack, Shelf, or Bin if needed.

  - **Make/Model**: Input the make or model if relevant.

3**. Set Display Options**: Decide whether to "Display All" results or limit to specific criteria.

4**. Initiate Search:** Click the "Search" button to generate a list of matching products.

5**. Review Results**: Check the displayed table for columns like Product Name, Part No., Mfr, Sell Price, Available, Allocated, On Hand, Purchased, Storage, and Order Qty to find the desired product.

~~6~~**. Adjust Search** (if needed): Modify the search criteria and click "Search" again to refine results.
