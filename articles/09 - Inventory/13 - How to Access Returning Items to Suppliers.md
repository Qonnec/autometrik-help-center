# How to Access Returning Items to Suppliers

Use the following procedure to **manage returned items.**

1.  **Navigate to Purchase Return Details**: Access the "Inventory" section, select "Purchase Order," and click on the specific purchase order reference number to view details, then navigate to the "Returns" tab.

2.  **Initiate Return Process**: Click on an existing return or create a new return by selecting the option to start a purchase return.

3.  **Enter Return Information**: Input the reference number, date, purchase order number, supplier details, and indicate if the return is for replacement.

4.  **Identify Products to Return**: Select the product from the purchase order, enter the part number, and specify the return quantity in the "Return Qty" column.

5.  **Verify Return Details**: Ensure the returned quantity matches the received quantity and calculate the amount based on the price.

6.  **Submit Return Request**: Save the return details to submit it for processing.

7.  **Review and Finalize**: Check the summary for accuracy, update the status to "Completed" once processed, and use the "View Credit Memo" option to document the return.

8.  **Cancel if Needed**: If the return is no longer required, click "Cancel Return" to abort the process.
