# How to Assign Approvers

Use the following procedure to **assign approvers.**

1.  **Navigate to Positions**: On the left sidebar, expand the "Administration" menu and click on "Positions". This opens the Positions list or details page.

2.  **Edit or Create Position**: Select an existing position (e.g., "ADMIN") from the list or click "New" to create one. In the Position Details, ensure the "Purchase Approver" field is set to "Yes". Adjust other fields like Mechanic, Service Advisor, Inspector, Invoice Approver, Purchaser, and Max Purchase Limit as needed. Click "Save Position" to apply changes.

3.  **Navigate to Employees**: On the left sidebar, expand the "People" menu and click on "Employees". This opens the Employees section.

4.  **Create New Employee**: Click "New" to open the New Employee creation page. Fill in required fields such as First Name, Last Name, Employee No, Birthday, Date Hired, Mobile No, and Address.

5.  **Assign Designation**: In the Designation field, select "ADMIN" (or the position configured as an approver) from the dropdown menu.

6.  **Assign User Account**: If needed, select or enter a User Account for login purposes.

7.  **Save Employee**: Review all details and click the save button to create the new employee account. This adds the employee as an approver since they have the admin designation.

8.  **Verify in Purchase Order Approval**: To assign the new approver to a specific purchase order, navigate to Inventory \> Purchase Order. Open or create a purchase order, then click "Submit for Approval". In the popup, select the new employee's name as the approver, set SMS if desired, and click "Send Approval Request". Close the popup to complete.
