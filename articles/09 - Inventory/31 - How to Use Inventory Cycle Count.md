# How to Use Inventory Cycle Count

Inventory Cycle Count is a feature that **allows users to regularly verify the quantity of a small set of inventory items instead of counting all items at once**. This helps maintain accurate stock levels with less disruption to daily operations. Selected items will automatically appear on the dashboard for review based on the settings you define.

**Why Use Cycle Count:**

  - Reduces time spent on full inventory counts

  - Improves inventory accuracy

  - Helps detect discrepancies early (loss, damage, or system errors)

  - Ideal for weekly or monthly verification of critical or fast‑moving items

**Inventory Cycle Count Settings:**

  - **Required Permissions**: To access and perform Inventory Cycle Counts, the user must have the appropriate permissions assigned by an administrator. Without the correct permission, Cycle Count options, dashboard popups, and quantity adjustment fields will not be visible or editable. Typical required permissions include:
    
    1.  View Inventory
    
    2.  Perform Cycle Count
    
    3.  Adjust Inventory Quantity
    
    4.  Access Dashboard Tasks or Alerts

\[***NOTE***: Permission names may vary depending on system configuration.\]

Use the following procedure to **navigate Inventory Cycle Count settings.**

1.  Navigate to **Settings** \> **Inventory Settings** \> **Cycle Count**.

2.  **Enable Cycle Count**: Set to ‘Yes’ to activate the Cycle Count feature. When enabled, the system will automatically select items for counting based on your configuration.

3.  **Cycle Count Number of Items**: Defines how many items will be included in each cycle count. These items will appear as a list on the dashboard for verification. Example: If set to 10, the system will prompt you to count 10 items per cycle.

4.  **Cycle Count Frequency (Days):** Determines how often (in days) a new cycle count list will be generated. Examples: 7 days \> Weekly cycle count, 30 days \> Monthly cycle count

**How Cycle Count Works:**

  - Cycle Count is enabled in Inventory Settings.

  - The system automatically selects items based on internal logic (such as stock movement or item priority).

  - On the scheduled frequency, a Cycle Count task appears on the dashboard.

  - The user opens the task and physically counts the listed items.

  - The user updates the actual quantity in the system.

  - Any discrepancies are recorded and inventory levels are adjusted accordingly.

**Dashboard Cycle Count List:**

A popup or notification appears on the dashboard when a cycle count is due. The list shows:

  - Item name

  - System quantity

  - Field to enter actual counted quantity

\[***NOTE***: Users only need to count the listed items, not the entire inventory.\]

**Best Practice:**

  - Set a small number of items per cycle to avoid disrupting operations.

  - Use shorter frequency intervals for high‑value or fast‑moving items.

  - Assign responsibility to a specific staff member for consistency.

  - Review discrepancies regularly to identify recurring issues.

**Common Scenarios:**

  - **Small shops**: 5–10 items weekly

  - **Medium inventory**: 10–20 items every 2 weeks

  - **Large inventory**: Daily cycle counts with rotating items

In summary, Inventory Cycle Count allows you to **maintain accurate stock levels by checking a small number of items on a regular schedule**. Instead of performing time‑consuming full inventory counts, users can rely on automated reminders and dashboard prompts to keep inventory data reliable and up to date.
