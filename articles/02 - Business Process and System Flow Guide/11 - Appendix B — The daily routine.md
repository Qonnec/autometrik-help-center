# Appendix B — The daily routine

| **When**       | **Who**         | **What**                                                                                   |
| -------------- | --------------- | ------------------------------------------------------------------------------------------ |
| Start of day   | Service advisor | Check the appointment calendar and the Jobs Board                                          |
| On arrival     | Service advisor | Confirm the appointment as *Attended*, raise the job order, clear pending inspection items |
| During the job | Mechanic        | Clock in and out; record inspection findings                                               |
| On completion  | Service advisor | Move to *Completed*, raise the invoice, release the vehicle                                |
| End of day     | Cashier         | Reconcile payments, run the Daily Collection Report                                        |
| Weekly         | Storekeeper     | Review stock quantities, raise purchase orders, run a cycle count on one section           |
| Monthly        | Accounts        | Supplier payments, AR follow-up, the journals and the statements                           |
| Per period     | HR              | Time sheets, leave and overtime approvals, run payroll                                     |
