# User Interface and Menu Navigation

The dashboard is the main screen you see when you log in. It’s divided into sections with colorful tiles and charts that give you a quick look at your shop’s performance. Here’s what you’ll find:

  - **Top Bar**: At the top, you’ll see the website address (app.autometric.ph) and open tabs like "Auto Shop Office - Dashboard."

  - **Main Display**: The center of the screen shows key information in easy-to-read boxes and charts:

| **Name**           | **Description**                                                                               |
| ------------------ | --------------------------------------------------------------------------------------------- |
| Job Orders         | A blue box showing the number of active job orders and a calendar icon to view details.       |
| Customers          | A blue box displaying the number of customers with a calendar icon for more info.             |
| Inventory          | A blue box showing the total items in stock) and low stock items) with a box icon.            |
| Profit & Loss      | A green box with a graph icon, showing your revenue and expenses for the month.               |
| Cash In/Out        | A green box with a money icon, tracking cash flow (e.g., 0.00 in and out).                    |
| Accounts           | A gray box with a building icon, showing account details like cash in bank.                   |
| Revenue Breakdown  | A green pie chart breaking down income sources (e.g., Parts and Accessories, Service Income). |
| Expenses Breakdown | A blue pie chart showing where your money goes (e.g., Cost of Sale, Bank Charges).            |
| 6-Month Sales      | A line graph on the right showing sales trends over the last six months.                      |

  - **User Panel**: On the top right, there’s a panel with your username membership details and options like Account Settings and Sign Out.

On the left side, there’s a collapsible menu with icons and sections to help you navigate the system. Click any section to expand it and access its features. Here’s how to use it:

| **Name**        | **Description**                                                                                                |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| Company Logo    | At the top, the logo takes you back to the main dashboard.                                                     |
| Dashboard       | This section (highlighted when active) shows the overview you’re currently viewing.                            |
| Vehicles        | Click this to manage vehicle-related information, like tracking cars in your shop.                             |
| Customers       | Use this to view and manage customer details and records.                                                      |
|                 |                                                                                                                |
| Product Inquiry | This section helps you look up product information or availability.                                            |
| Operations      | Click here to handle tasks like job orders, estimates, and repairs (expands to show more options).             |
| Inventory       | Use this to manage stock, purchase orders, and supplier details (expands for more features).                   |
| CRM             | This section is for customer relationship tools, like sending messages or reminders (expands to show options). |
| People          | Click to manage employee information, holidays, and leave requests (expands for more details).                 |
| Accounting      | Use this to handle financial tasks like payments and reports (expands to show more options).                   |
| Reports         | This section lets you generate reports on sales, jobs, and more (expands for detailed reports).                |
| Administration  | Click here to set up users, services, and system settings (expands for advanced options).                      |

To navigate, simply click a section name to open it. If it has a small arrow, click it to see more options inside. You can collapse the menu by clicking the arrow at the top to free up screen space when needed.
