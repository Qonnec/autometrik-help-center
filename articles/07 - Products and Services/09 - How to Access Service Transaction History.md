# How to Access Service Transaction History

Use the following procedure to **view transaction history.**

1.  Click **Vehicles** on the menu.

2.  **Select a vehicle** from the list.

3.  Navigate to the **Service History** tab.

4.  Review the transaction details:

<!-- end list -->

  - **Reference No**: Unique identifier.

  - **Services**: Specific services performed (e.g., "AC Accumulator Replacement", "AC Clutch Cycling Switch Replacement").

  - **Customer/Supplier/Employee**: Personnel involved.

  - **Amount**: Cost of each service.

  - **Date**: When the service was completed

  - **Status**: Current status (e.g., "Released").

5**. Save** the entry.

6**. Filter or search records** using the Search or Filter options if available.
