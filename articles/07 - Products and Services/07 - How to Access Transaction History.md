# How to Access Transaction History

Use the following procedure to **track transaction history.**

1.  Click **Inventory** on the menu.

2.  Select **Products** from the submenu.

3.  **Choose your selected product** from the product list.

4.  **Navigate to the Transactions** tab.

5.  Review the transaction details:
    
      - **Reference No**: Unique identifier for the transaction.
    
      - **Transaction Type**: Indicates the type of transaction (e.g., "Initial Quantity").
    
      - **Customer/Supplier/Employee**: Party involved (not specified in this case).
    
      - **Quantity**: Amount involved (e.g., 5,000.00 for Initial Quantity).
    
      - **Price**: Cost per unit (e.g., 65.47) and total value (e.g., 327,350.00).
    
      - **Inventory**: Current inventory level after the transaction (e.g., 5,000).
    
      - **Date**: When the transaction occurred (e.g., 11-14-2024).

6.  **Filter transactions** using the Filter option **to sort or search specific records**.
