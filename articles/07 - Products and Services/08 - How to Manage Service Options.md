# How to Manage Service Options

Use the following procedure to **edit an existing service option.**

1.  Click **Administration** on the menu.

2.  Click **Services** on the submenu.

3.  Review the list of services, which includes:

<!-- end list -->

  - **Name**: Service description

  - **Code**: Unique service code.

  - **Rate**: Standard charge (e.g., 650.00 /hr).

  - **Standard Hours**: Time allocated.

  - **Group**: Service category group (e.g., "ENGINE").

  - **Category**: Specific category (e.g., "ENGINE").

  - **Date**: Date of entry or last update.

4\. **Select a service** to edit its details.

5\. **Save changes.**

Use the following procedure to **create a new service option.**

1.  Click **Administration** on the menu.

2.  Click **Services** on the submenu.

3.  Click the **New button** (top right).

4.  Fill in the Service Information:

<!-- end list -->

  - **Name**: Enter the service name.

  - **Code**: Assign a unique code.

  - **Standard Rate**: Set the charge.

  - **Standard Rate** Standard Hours: Enter the time.

  - **Group**: Type or select a group.

  - **Category**: Type or select a category.

  - **Allow** **Rate** **Override**: Check "Yes" if the rate can be adjusted.

  - **Do not require Mechanic**: Check "No" unless optional.

  - **Enable Classification Rates**: Check "No" unless needed.

  - **Next Service Reminder**: Set days for follow-up.

  - **Display Standard Hours**: Check "No" unless visible to customers.

  - **Replacement**: Check "No" unless it involves part replacement.

  - **Display Notes**: Check "No" unless notes are needed.

  - **Incentive**: Type or select an incentive name (optional).

5\. Click **Add Service** to save the new service.
