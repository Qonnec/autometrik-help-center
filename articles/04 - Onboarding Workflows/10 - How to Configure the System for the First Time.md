# How to Configure the System for the First Time

The Initial System Configuration in the AutoMetrik system is the **process of setting up the platform to match your auto shop’s specific needs when you first start using it**. This ensures the system is ready for daily operations. It tailors the system to your shop’s structure, making it easier to manage customers, jobs, inventory, and finances from day one.

Use the following procedure to **configure the system for the first time**.

1.  **Start the Configuration**: Log in for the first time. The system may launch an Initial Configuration Wizard automatically, or you can find it under the Administration section.

2.  **Follow the Steps**: Go through each screen, entering required details like shop info and user accounts.

3.  **Set Up Services and Products**: Add your service categories and product types as prompted.

4.  **Configure Finances**: Input your preferred financial settings, such as currency or tax options.

5.  **Add Locations**: If applicable, set up multiple branches or locations.

6.  **Import Data**: Use the import tool to upload existing records (e.g., customers, inventory).

7.  **Save and Review**: Click "Finish" or "Save" to complete the setup, then check the dashboard to ensure everything is correct.
