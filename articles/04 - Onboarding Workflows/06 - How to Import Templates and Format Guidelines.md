# How to Import Templates and Format Guidelines

An Import Template is **a pre-made file (like a CSV) provided by the system** that shows the exact structure you need for your data. It includes column headers (e.g., Name, Code, Email) to match the fields in AutoMetrik. It ensures your data fits the system’s requirements, making the import process easier and reducing errors.

Use the following procedure to **import template**.

1.  Go to the **Import** section (e.g., under Customers).

2.  Click **Download Template to** get the file.

3.  **Fill in your data** (e.g., customer names, contact info) under the correct columns using Google Sheets or Excel, then upload it using the Choose File option.

Format Guidelines are specific rules about how your data should be organized in the template. They tell you what kind of information goes in each column and how it should be written. Following these rules prevents mistakes during import, like mismatched data or missing fields.

Examples of Guidelines:

  - **Name:** Enter full names (e.g., "John Doe") with no extra spaces.

  - **Code:** Use a unique code (e.g., "CUST-001") for each entry.

  - **Email:** Include valid email addresses (e.g., "john@example.com").

  - **Date:** Use a standard format (e.g., MM-DD-YYYY) for dates like contact dates.

  - **Required Fields:** Some columns (like Name) must be filled; others (like Email) might be optional.

\[***NOTE***: Always check the guidelines (often provided on the import page or in the template instructions) before filling your file. Stick to these rules to ensure a successful import.\]
