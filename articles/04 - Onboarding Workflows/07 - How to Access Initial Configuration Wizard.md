# How to Access Initial Configuration Wizard

It is a tool that walks you through the **basic setup process** to get the system ready for your business. It covers essential settings like user accounts, shop details, and service categories. It makes setup easy by guiding you through each step, ensuring you don’t miss anything important. This helps you start using the system quickly and correctly.

  - **Set Up Your Shop**: Enter basic info like your shop’s name, address, and contact details.

  - **Add Users**: Create accounts for yourself and your team, assigning roles like manager or mechanic.

  - **Define Services**: Set up the types of services your shop offers, such as oil changes or tire repairs.

  - **Configure Preferences**: Choose settings like currency, time zone, or invoice numbering.

  - **Add Initial Data**: Optionally import or enter starting data, like a list of products or customers.
