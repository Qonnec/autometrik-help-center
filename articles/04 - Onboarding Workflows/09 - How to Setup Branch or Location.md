# How to Setup Branch or Location

The Branch or Location Setup in the AutoMetrik system allows you **to manage multiple branches or locations** for your auto shop, ensuring all sites are organized and tracked efficiently. It helps you keep track of inventory, customers, and operations across all locations, making it easier to manage a multi-branch business.

Use the following procedure to **setup a branch**.

1.  **Access the Dashboard**: Log in to the Auto Shop Office application and navigate to the main dashboard, where key metrics like revenue, expenses, customers, inventory, and vehicles are displayed.

2.  **Locate the Select Location Dropdown**: In the upper left corner of the dashboard, find the "Select Location" button or dropdown menu (it may appear as a blue bar with the current location name).

3.  **Click to Open the Dropdown**: Click on the "Select Location" button to expand the list of available branches. This will show all branches associated with your account.

4.  **Choose a Branch**: Scroll through the list if necessary and click on the desired branch to select it. The dashboard will refresh to display data and settings specific to that branch.

5.  **Verify Selection**: Confirm the selected branch is now shown in the dropdown (e.g., updated to the new branch name), and review the dashboard metrics to ensure they reflect the chosen branch's information.

6.  **Edit Branch Settings (Optional)**: If needed, go to "Administration" in the left sidebar, then select "Locations" to edit settings for the selected or any other branch.

\[***NOTE***: Qonnec provides the initial accounts for each branch, but users can customize settings like branding, print templates, tax, discounts, inventory, and other configurations per branch.\]
