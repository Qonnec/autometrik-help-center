# How to Issue Leave and Loans

Use the following procedure to **manage leave requests.**

1.  **Navigate to the People** section from the left sidebar.

2.  Click on "**Leave Request**" under the People menu.

3.  Click the "**New**" button at the top right to create a new leave request.

4.  Fill in the required fields under "Leave Request Information":

<!-- end list -->

  - Enter the **Employee name**.

  - Set the **Date From**.

  - Set the **Time** (e.g., 12:00 AM).

  - Set the **Date** **To**.

  - Set the **Time** (e.g., 12:00 AM).

  - Select the **Status** (e.g., New).

  - Choose the **Request Type** (e.g., Vacation Leave).

  - Add **Remarks** if needed (optional).

5\. Click "**Add Leave Request**" to submit the request.
