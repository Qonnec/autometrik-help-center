# How to Manage Overtime Requests

Use the following procedure to **manage overtime requests.**

1.  **Navigate to the People** section from the left sidebar.

2.  Click on "**Overtime Request**" under the People menu to view the list of requests.

3.  **Review the details** such as Employee, Date From, Date To, Status, and Date.

4.  To **create a new overtime** request, click the "**New**" button at the top right.

5.  Fill in the required fields under "**Overtime Request Information**":

<!-- end list -->

  - Enter the **Employee name**.

  - Set the **Date** **From.**

  - Set the **Time**.

  - Set the **Date** **To.**

  - Set the **Time**.

  - Select the **Status** (e.g., New, Approved, Denied, Cancelled).

  - Add **Remarks** if needed (optional).

6\. Click "**Add Overtime Request**" to submit the request.

7\. To **update an existing request**, select it from the list and modify the status or details as needed.
