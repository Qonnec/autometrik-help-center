# How to Manage Enterprises

Use the following procedure to **manage branch.**

1.  **Access the Locations Section**:

<!-- end list -->

  - Navigate to the "Administration" menu on the left sidebar.

  - Select "Locations" to view the list of branches. The initial screen shows a table with details such as Name, Address, Telephone No, Organization, Enterprise, and Date for each location.

2\. **View and Select a Branch**: From the locations list, click on a specific branch to access its details. This will take you to the branch's configuration page.

3\. **Configure Branch Settings**:

  - **Branding Information**: Update the logos that appear on printouts and software for the branch. Upload or adjust the logo as needed and save the changes.

  - **Print Settings**: Customize print templates for various documents (e.g., Estimates, Job Orders, Sales Orders, Invoices, etc.) specific to the branch:

  - Edit the Print Header Text, Title, Terms, and Footer for each document type.

  - Enable or disable features like signatures, discount breakdowns, or approvers as required (e.g., enable estimate signatures with "Yes" or "No").

  - **Custom Print Templates**: Assign or create custom templates (e.g., Estimate Template, Job Order Template) for specific branch needs. Save these settings to apply them.

  - **Operating Hours**: Set the business hours for the branch, including start time, end time, and days of operation (e.g., Monday to Friday, 9:00 AM to 5:00 PM PST).

4\. **Save Changes**: After adjusting settings for a branch, click the "Save Location" or "Save Settings" button to ensure the changes are applied to that specific branch.

5\. **Manage Multiple Branches**:

  - Repeat the process for each branch listed. Each branch retains its own settings, allowing for separate configurations (e.g., different phone numbers, addresses, or print layouts).

  - Use the search function or scroll through the list to switch between branches and update their settings as needed.

6\. **User Access**: Ensure that users can only access the branches assigned to them. This might involve setting permissions elsewhere in the administration panel, but the location settings themselves are branch-specific and will reflect based on the user's selected branch.

By following these steps, you can effectively manage multiple branches with separate settings tailored to each location's operational needs. Each branch's configuration is independent, allowing for flexibility in branding, document handling, and other administrative details.
