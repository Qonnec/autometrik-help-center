# How to Set Positions

Use the following procedure to **set positions.**

1.  **Navigation**: From the main dashboard, click on Administration in the left-hand menu, then select Positions.

2.  **View Positions**: On the Positions page, you will see a list of existing positions, including the name and date created.

3.  **Create New Position**: To add a new position, click the New button in the top right corner.

4.  **Enter Position Details**: Fill in the required fields such as the position name, mechanic status, service advisor status, inspector status, invoice approver status, purchaser status, max purchase limit, and purchase approver status.

5.  **Save Position**: After entering the details, click the Add Position or Save Position button to store the new or edited position.

6.  **Edit Position**: To modify an existing position, click the action icon (three dots) next to the position name and select Edit, then update the details and save.

7.  **Delete Position**: To remove a position, click the action icon next to the position name and select Delete, then confirm the action if prompted.

8.  **Search Positions**: Use the Search field at the top to find a specific position by name.
