# How to Access Service Groups

Use the following procedure to **manage service groups.**

1.  On the left sidebar, locate and click on **Administration**.

2.  From the expanded menu, click on **Service** **Groups**.

3.  On the Service Groups page, click the **New** button in the top-right corner.

4.  Fill in the **Name** and **Description** fields with the desired information for the new service group.

5.  Select the **Default Service Account** and **Default Expense Account** from the dropdown menus, or type in the names if needed.

6.  If applicable, set a Default Group or leave it as "No".

7.  Click the **Add Service Group** button to save the new group.
