# How to Manage Parameter Group

Use the following procedure to **manage parameter groups.**

1.  **Navigation**: From the main dashboard, click on Administration in the left-hand menu, then select Parameter Groups.

2.  **View Parameter Groups**: On the Parameter Groups page, you will see a list of existing groups, including the code, name, and date created.

3.  **Create New Parameter Group**: To add a new parameter group, click the New button in the top right corner.

4.  **Enter Parameter Group Details**: Fill in the required fields such as the code, name, and description for the new parameter group.

5.  **Save Parameter Group**: After entering the details, click the Add Parameter Group button to store the new group.

6.  **Edit Parameter Group**: To modify an existing group, click the action icon (three dots) next to the group name and select Edit, then update the details and save.

7.  **Delete Parameter Group**: To remove a group, click the action icon next to the group name and select Delete, then confirm the action if prompted.

8.  **Search Parameter Groups**: Use the Search field at the top to find a specific parameter group by code or name.
