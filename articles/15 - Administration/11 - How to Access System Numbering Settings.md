# How to Access System Numbering Settings

Use the following procedure to **manage system numbering.**

1.  **Navigation**: From the main dashboard, click on Administration in the left-hand menu, then select System Numbers from the submenu.

2.  **Access Details**: Once on the System Numbers page, locate the DETAILS section where you can view and edit the system number settings.

3.  **Review Prefixes and Numbers**: Check the current prefixes and corresponding numbers for each category.

4.  **Edit Prefixes** (if needed): Click into the prefix field and type a new prefix if you want to change it.

5.  **Adjust Numbers** (if needed): Click into the number field and enter a new starting number if you want to reset or adjust it.

6.  **Enable/Disable Fields**: Ensure the "Enabled" toggle is active for the fields you want to use. For fields marked "Disabled," leave them as is unless you need to enable them by toggling the switch.

7.  **Save Changes**: After making any adjustments, click the Save System Numbers button at the bottom of the page to apply the changes.

8.  **Verify**: Confirm that the updated prefixes and numbers are reflected in the system by checking the fields or generating a new document to ensure the new settings are in effect.
