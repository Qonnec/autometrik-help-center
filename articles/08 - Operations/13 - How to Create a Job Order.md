# How to Create a Job Order

Use the following procedure to **create a job order.**

1.  From the left sidebar, click on "**Operations**."

2.  Select "**Job Order**" from the dropdown menu.

3.  Click the "**New**" button at the top right to start a new job order.

4.  Fill in the required fields:

<!-- end list -->

  - **Date**: Enter the date (e.g., 12 Jun 2025) or use the calendar icon.

  - **Promised Date**: Enter the promised completion date (e.g., 12 Jun 2025) or use the calendar icon.

  - **Status**: Select the status (e.g., Open) from the dropdown.

  - **Customer**: Type the customer name.

  - **Vehicle**: Type the vehicle name or plate number.

  - **Service** Advisor: Select the service advisor (e.g., LUIS MATERA) from the dropdown.

  - **Mileage**: Enter the mileage (e.g., 0 km).

  - **Customer PO**: Enter the customer purchase order if applicable.

  - **Customer Source Channel**: Select the source channel.

  - **Labor**: Type the service name (e.g., Temperature Sending Unit Replacement), select the mechanic, set the rate (e.g., 650.00), hours (e.g., 1.5), and calculate the amount. Click "**+ Add Service**" to add more services.

  - **Parts & Materials**: Type the product name or part number, set the price and quantity, and adjust the discount if needed. Click "**+ Add Product**" to add more items.

5\. Scroll to the "**Summary**" section and add any remarks if necessary.

6\. Click the "**Create Job Order**" button to save the job order as "Open”.
