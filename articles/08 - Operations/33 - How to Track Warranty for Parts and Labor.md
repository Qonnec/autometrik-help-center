# How to Track Warranty for Parts and Labor

Use the following procedure to **edit an existing warranty.**

1.  **Access Warranties**: Navigate to the "Operations" menu on the left sidebar and click on "Warranties".

2.  **Locate the Warranty**: In the warranties list, find the existing warranty you wish to edit (e.g., Reference No. WT0001002) and click on it to open the details.

3.  **Modify Warranty Information:**

<!-- end list -->

  - **Reference No:** View the system-generated reference number, which cannot be edited.

  - **Issue Date**: Update the issue date if needed.

  - **Expiry Date**: Adjust the expiry date if necessary.

  - **Status**: Change the status (e.g., from "New" to another status) if applicable.

  - **Customer**: Edit the customer name by typing or selecting a new name from the dropdown.

  - **Job Order**: Update the associated job order if required.

  - **Warranty** **Template**: Select a different template if needed.

  - **Km Reading**: Modify the kilometer reading if applicable.

  - **Covered Services**: Check or uncheck the services covered (e.g., Shock Absorber Replacement).

  - **Covered Products**: Check or uncheck the products covered (e.g., NITROTECH Shock Absorber Front Left).

  - **Remarks**: Update any additional notes in the remarks section.

  - **Notes for Internal Use**: Edit internal notes if necessary.

  - **Terms & Conditions**: Modify the terms and conditions text if required.

4\. **Save Changes**: Click the "Save Warranty" button to apply the edits.

Use the following procedure to **create a new warranty.**

1.  **Access Warranties**: Navigate to the "Operations" menu on the left sidebar and click on "Warranties".

2.  **Create New Warranty**: Click the "New" button in the top right corner to open the "New Warranty" form.

3.  **Enter Warranty Information**:

<!-- end list -->

  - **Reference No**: Leave as "System Generated" or enter a custom reference if needed.

  - **Issue Date**: Set the issue date using the calendar.

  - **Expiry Date**: Set the expiry date using the calendar.

  - **Status**: Select the status (e.g., "New") from the dropdown.

  - **Customer**: Type or select the customer name from the dropdown.

  - **Job Order**: Enter or select the associated job order from the dropdown.

  - **Km Reading**: Input the kilometer reading if applicable.

  - **Warranty Template**: Select a template (e.g., "Shock Absorber Replacement Warr") from the dropdown.

  - **Covered Services**: Check the boxes for services covered.

  - **Covered Products**: Check the boxes for products covered.

  - **Remarks**: Add any additional notes in the remarks section.

  - **Notes for Internal** **Use**: Enter internal notes if necessary.

  - **Terms & Conditions**: Edit or accept the default terms and conditions text.

4\. **Save the** **Warranty**: Click the "Create Warranty" button to save the new warranty.
