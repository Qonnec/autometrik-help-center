# How to Create and Convert an Estimate

Use the following procedure to **create a new estimate.**

1.  From the left sidebar, click on "**Operations**."

2.  Select "**Estimate**" from the dropdown menu.

3.  Click the "**New**" button at the top right to start a new estimate.

4.  Fill in the required fields:

<!-- end list -->

  - **Date**: Enter the date or use the calendar icon.

  - **Expiry**: Enter the expiry date or use the calendar icon.

  - **Estimated Days**: Input the number of days if applicable.

  - **Customer**: Type the customer name.

  - **Vehicle**: Type the vehicle name or plate number.

  - **Service** **Advisor**: Select the service advisor from the dropdown.

  - **Mileage**: Enter the mileage.

  - **Customer Source Channel**: Select the source channel.

  - **Customer PO**: Enter the customer purchase order if applicable.

  - **Labor**: Type the service name, set the rate and hours, and adjust the discount if needed. Click "+ Add Service" to add more services.

  - **Parts & Materials**: Type the product name or part number, set the price and quantity, and adjust the discount if needed. Click "+ Add Product" to add more items.

5\. Scroll to the "**Summary**" section at the bottom and add any remarks if necessary.

6\. Click the "**Create Estimate**" button to save the new estimate.

Use the following procedure to **convert an estimate.**

1.  **Locate the newly created estimate or an estimate that has an open status** in the "**Estimates**" list.

2.  Click the "**Actions**" options next to the estimate.

3.  Select "**Create a Job Order**" from the menu.

4.  **Fill out the necessary information** for the job order (e.g., job details, assigned technician, etc.) as prompted.

5.  Click the "**Create Job Order**" button to save the job order.

6.  The **status of the estimate will be converted** accordingly.
