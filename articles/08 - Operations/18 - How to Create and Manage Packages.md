# How to Create and Manage Packages

Packages are **pre-defined sets of jobs and parts** (also called “canned jobs”) that can be applied quickly when creating estimates or job orders.  
They are often used for common services such as **oil change**, **brake service**, or **tune-up**, and can include **discounted rates** for bundled items.

When adding parts to a package, you can:

  - **Select a specific product** (e.g., “Engine Oil – Brand X 4L”).

  - **Select a category** (e.g., “Oil Filter”) so the system will prompt you to choose a specific item during estimate or job order creation.
    
      - This is useful when the part varies depending on the car (e.g., different oil filters for different models).
    
      - When a category is used, Autometrik will look for items under that category in your inventory.

## Viewing Existing Packages
1.  Click **Administration** on the menu.

2.  Select **Packages** from the submenu.

3.  Review the list of packages, which includes:
    
      - **Name** – Package description.
    
      - **Amount** – Total cost of the package.
    
      - **Date** – Date of creation or last update.

## Creating a New Package
1.  Click **Administration** on the menu.

2.  Select **Packages** from the submenu.

3.  Click the **New** button (top right).

4.  **Fill in the Package Info:**
    
      - **Name:** Enter the package name (e.g., “New Brake Service Package”).
    
      - **Code:** Assign a unique code (e.g., “BP01”).

5.  **Configure Line Items Printout Options:  
    **These settings control how the package details appear on printed estimates or job orders.
    
      - **Hide Services:** Hides the list of services in the printout (only the package name and total will be shown).
    
      - **Hide Parts & Materials:** Hides the list of parts and materials in the printout.
    
      - **Display Code:** Shows the package code in the printout — useful when multiple packages are used in one job order so you can identify each one.
    
      - **Hide Amounts:** Hides the individual amounts for each service/part so that only the **total package amount** is shown.
    
      - **Replacement Text:** Optional text that will appear in place of the hidden details (if applicable).

6.  **Add Services (optional):**
    
      - Under **Labor**, click **+ Add Service**.
    
      - Type or select a service name.
    
      - Set the **Rate** and **Hours**, then the amount will be calculated automatically.

7.  **Add Parts & Materials (optional):**
    
      - Under **Parts & Materials**, click **+ Add Product**.
    
      - You can either:
        
          - Select a **specific product** from your inventory.
        
          - Select a **category** (e.g., “Oil Filter”) — the exact item will be chosen later when creating the estimate or job order.
    
      - Enter **Price** and **Quantity** to calculate the amount (for specific products).
    
      - If using a category, price will be determined once the actual item is selected in the job order.

8.  **Add Remarks (optional):**
    
      - Enter any additional notes or package details.

9.  **Use the Summary section** to review the total package details.

10. Click **Create Package** or **Save Package** to store the package in the system.

## Editing an Existing Package
1.  From the package list, select the package you want to edit.

2.  Update **Package Info** or **Line Items Printout Options** as needed.

3.  Modify or replace services, products, or categories in the package.

4.  Click **Save Package** to apply changes.

**Best Practice:**

  - Use **categories** for parts that vary by vehicle model to avoid creating multiple packages for each variation.

  - Use **specific products** for parts that never change for that job.

  - Use **Hide Amounts** when offering a single flat rate for a package to keep individual prices confidential.

  - Applying packages speeds up estimate and job order creation, ensures consistent pricing, and maintains service standards.
