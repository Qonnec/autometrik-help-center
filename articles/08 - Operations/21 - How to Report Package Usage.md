# How to Report Package Usage

Use the following procedure to **generate a report for package usage.**

1.  **Access the Top Selling Services Report**: Navigate to the "Reports" menu on the left sidebar and click on "Top Selling Services".

2.  Apply Filters:

<!-- end list -->

  - **Service**: Type or select the service name from the dropdown to filter specific services.

  - **Service Group**: Type or select the service group from the dropdown to filter by group.

  - **Category**: Type or select the category from the dropdown to filter by category.

  - **From**: Set the start date (e.g., 1 Jun 2025) for the reporting period.

  - **To**: Set the end date (e.g., 19 Jun 2025) for the reporting period.

  - **Sort by**: Choose to sort by "Count" or "Amount" based on your preference.

3\. **Generate the Report**: Click the "Generate Report" button to create the report based on the applied filters.

4\. Review Package Usage:

  - The generated report will display the top selling services, which may include services tied to packages.

  - Analyze the "Count" or "Amount" data to identify the usage frequency or revenue contribution of packages, as packages often bundle services and parts.
