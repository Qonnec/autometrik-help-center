# How to Apply Packages in Job Order

Use the following procedure to **use a service package.**

1.  When creating an **Estimate** or **Job Order**, look for the **box icon button** at the upper-right corner of the screen.

2.  Click the button to open the **Package List**.

3.  Select a package from the list.

4.  The system will automatically populate the **services** and **parts** exactly as they were set up in the package.
