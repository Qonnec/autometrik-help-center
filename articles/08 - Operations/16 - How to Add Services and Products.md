# How to Add Services and Products

Use the following procedure to **create a new service option.**

1.  Click **Administration** on the menu.

2.  Click **Services** on the submenu.

3.  Click the **New button** (top right).

4.  Fill in the Service Information:

<!-- end list -->

  - **Name**: Enter the service name.

  - **Code**: Assign a unique code.

  - **Standard Rate**: Set the charge.

  - **Standard Rate** Standard Hours: Enter the time.

  - **Group**: Type or select a group.

  - **Category**: Type or select a category.

  - **Allow** **Rate** **Override**: Check "Yes" if the rate can be adjusted.

  - **Do not require Mechanic**: Check "No" unless optional.

  - **Enable Classification Rates**: Check "No" unless needed.

  - **Next Service Reminder**: Set days for follow-up.

  - **Display Standard Hours**: Check "No" unless visible to customers.

  - **Replacement**: Check "No" unless it involves part replacement.

  - **Display Notes**: Check "No" unless notes are needed.

  - **Incentive**: Type or select an incentive name (optional).

5\. Click **Add Service** to save the new service.

Use the following procedure to **create a new product option.**

1.  **Access the Products Section**: Navigate to the "Inventory" menu on the left sidebar and click on "Products".

2.  **Create a New Product**: Click the "New" button in the top right corner of the Products page to open the "New Product" form.

3.  Enter Product Information:

<!-- end list -->

  - **Name**: Type the product name in the "Name" field.

  - **Print Display Name**: Enter the name to be displayed on printed materials in the "Print Display Name" field.

  - **Part No**: Input the part number in the "Part No" field.

  - **Product** **Group**: Select "PARTS" (or the appropriate group) from the dropdown menu.

  - **Category**: Type or select the category name from the dropdown.

  - **Unit of Measure**: Choose "PC" (or the relevant unit) from the dropdown.

  - **Manufacturer**: Type or select the manufacturer name from the dropdown.

  - **Manufacturer** **No**: Enter the manufacturer number if applicable.

  - **Description**: Add a description of the product in the "Description" field.

  - **Color**: Specify the color if relevant.

  - **Expiry Date**: Set an expiry date if applicable.

  - **Serialized**: Check "No" unless the product requires serialization.

  - **Display Notes**: Check "No" unless notes need to be displayed.

  - **Incentive:** Select an incentive if applicable from the dropdown.

4\. Set Price Information:

  - **Purchase** **Cost**: Enter the purchase cost and select the unit.

  - **Product Pricing**: Choose "FIXED" (or another option) from the dropdown.

  - **Markup Rate**: Enter the markup percentage.

  - **Sell Price**: The sell price will be calculated based on the purchase cost and markup rate.

5\. Configure Inventory Details:

  - **Re-order Point**: Set the minimum stock level to trigger a reorder.

  - **Safety Stock Level**: Set the safety stock level.

  - **Storage Location**: Specify Rack, Shelf, and Bin details if needed.

  - **Min Order**: Set the minimum order quantity.

  - **Order Multiple**: Set the order multiple quantity.

  - **Initial Quantity**: Enter the initial stock quantity.

  - **As-Of Date**: Set the date to today.

  - **Track Inventory**: Check "YES" to track inventory for this product.

6\. **Save the Product**: Click the "Add Product" button to save the new product entry.
