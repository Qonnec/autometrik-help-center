# How to Access Cash Transactions

Use the following procedure to **generate a cash transaction report.**

1.  **Navigate to the "Accounting"** section from the left sidebar.

2.  Click on "**Cash Transactions**" under the Accounting menu.

3.  In the "**Report Filter**" section:

<!-- end list -->

  - Set the "**From**" date.

  - Set the "**To**" date.

4. **Review the selected date range** to ensure accuracy.

5\. Click the "**Generate Report**" button to create the report.
